# docs/tecnicos

Documentos que **não** pertencem a uma task. O prefixo `m.n` de `docs/` é
reservado pro número do bloco no ClickUp (`4.3-status-entrega.md` é a entrega do
bloco 4.3), então nota técnica, processo e auditoria vivem aqui, com nome
descritivo.

| Documento | O que é |
|---|---|
| `plano-validacao.md` | as cinco camadas de `npm run validar` e a regra de rodá-las antes de declarar qualquer task pronta |
| `correcoes-listagens-e-obras.md` | os três bugs achados ao fechar as lacunas de validação do bloco 4.3, e o que mudou no plano por causa deles |
| `auditoria-repositorio-deploy-documentacao.pdf` | auditoria do repositório (anterior a esta série) |

Regra prática: se o documento morre junto com a task, use `m.n-` em `docs/`.
Se ele continua valendo depois, é daqui.
